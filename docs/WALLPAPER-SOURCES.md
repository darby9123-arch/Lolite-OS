# Wallpaper collections

`All` and normal categories contain Lolite-hosted uploads. `Embedded Wallpapers` contains the 840 LivelyWallpaper.app streams and 40 MotionBGS entries. Both providers use video elements, not iframe pages, but their videos remain hosted by third parties. Favourites can contain either kind.

The MotionBGS set keeps all 16 existing IDs and adds 24 entries from the previously checked source set, including GTA IV, GTA V/VI and Minecraft scenes. Download URLs use trailing slashes, and Original quality selects the 4K source when one is available. Balanced retains HD and Performance prefers a smaller preview where supplied. The new GTA IV entry has a confirmed source poster and preview. Other entries retain labelled placeholders where source posters could not be verified; the bulk metadata check was blocked by the provider. A 4K URL does not guarantee playback availability on every network.

The user's `Live Wallpapers.zip` has **not** been imported. It is approximately 2.6 GB, remains private on Drive, and exceeds the connected downloader's 256 MB limit. No Google Drive iframe or placeholder catalogue is presented as an imported file. Transfer needs an accessible download link or smaller uploaded files before actual videos can be hosted.

Quality preferences, pause/reduced-motion behaviour, wallpaper favourites, uploaded-file thumbnails and the single-decoder performance default are preserved.
